What the numbers mean

  • kev-span 1.5B beats the generative student on 6 of 9 fields and ties 1; it loses on parent_number and subject.
  • “Unit exact” (all 9 right) is similar: 0.390 vs 0.407. kev wins more fields, the LLM more whole units.
  • The LLM failed in ways kev cannot: 6 units of invalid JSON, invented dates, subjects translated to English.
  • kev's misses are boundary or null decisions: truncating 105/105 to 105, or picking null when the value is printed.
  • Per held-out source: 0.93, 0.84, 0.91, 0.90.
Input

What the model reads: one token sequence, no prompt

The sentence tokens come first. Then one branch per type, written from the schema as ⏎<|fim_prefix|>NAME: description<|fim_suffix|>. Qwen's reserved fill-in-the-middle tokens are reused as markers, and the last token of each branch is the <decide> token whose hidden state asks the question. Each branch's position ids restart right after the sentence, so no type sits “further away” than another.

Branches used for NER (the dataset's own instruction wording):

  • PER: person
  • ORG: organization; organizations can represent other groups of people; nationalities are not organizations
  • LOC: location; nationalities are not locations

Input · attention

The attention mask keeps the questions independent

Row = the token doing the attending, column = the token it may read. sentence ↔ sentence (bidirectional in the winning model), PER, ORG, LOC. Each branch reads the whole sentence and itself (causally), never another branch, so all types are answered in one pass. At start-up the code edits branch 0 and asserts branch 1's scores do not move (measured drift 0.00).

Decoding

From tensor to entities: three lines of plain Python

  1. Take every cell whose logit is above the threshold picked on dev (-2.0).
  2. Sort them by score, best first.
  3. Keep a span unless it overlaps a span already kept (UNER is flat). Map its tokens to character offsets.

Field extraction I/O · production model

The same idea on long documents: one span or “not printed” per field

For typed fields the head is a start pointer and an end pointer from each <decide> token over the document tokens, plus a learned null slot for “not printed here”. The best span competes with null; a normaliser picked by the field's declared type (date, number, text) turns the span into the value. The 9 branches come from the task schema:

fieldtypebranch description (verbatim from the schema)
datedateThe date this section's OWN act bears, as ISO 8601 YYYY-MM-DD, from the line under its letterhead (usually after «від»). The month may be spelled as a word. Null if this section only references another act's date, or shows no date.
numbertextThis section's OWN registration number as printed, without the «№» sign — digits plus any suffix the source attaches («62-2276/2025», «3095-53/VIII»). A blank placeholder (a run of underscores or dots) is null, not a guess. Null if this section only references another act's number.
parent_datedateThe date of the act this section is attached to, as ISO 8601 YYYY-MM-DD, read from its «Додаток до …» / «ЗАТВЕРДЖЕНО …» / «СХВАЛЕНО …» line. Null when this section is the act itself.
parent_numbertextThe registration number of the act this section is attached to, as printed without the «№» sign. Null when this section is the act itself, or when the reference line leaves the number blank.
annex_notextThis section's own ordinal among the annexes, as printed — «Додаток №1» is 1, «Додаток 2.1» is 2.1. Null when the section is not numbered as an annex.
session_nonumberThe ordinal of the sitting the act was taken at, as a bare integer — whether printed on this section or on the parent act it names. Words count: «шістдесят другої сесії» is 62.
convocation_nonumberThe ordinal of the convocation, as a bare integer. Usually a Roman numeral: «VIII скликання» is 8.
placetextThe settlement line as printed, keeping its abbreviation exactly («м. Узина», «с. Студена», «селище Журавно»). Do not expand or normalise the abbreviation. Null if the section prints no settlement line — never derive one from the body's name.
subjecttextThis section's own title — the «Про …» clause on an act, or the annex's own heading («Структура та штатна чисельність …»). One line, joined if it wraps. Null if the section has no title.

Caveats

What these results do not show yet

  • One training seed per model. The bootstrap intervals cover test sampling, not seed-to-seed variance; two more 4B seeds (~15 min of H100 each) would settle it.
  • Cost: the 4B model runs at 214 sentences/s vs RoBERTa's 2,967, about 14× the GPU cost per sentence. Both are far below a generative LLM.
  • The production-field evaluation is small (59 units); its differences are indicative, the NER benchmark is the statistically meaningful one.
  • About 1% of NER gold is unreachable because its boundary falls inside a Qwen token.
  • Types never seen in training have not been tested.
